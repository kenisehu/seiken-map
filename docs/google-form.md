# 施設属性 回収用 Googleフォーム 設計

掲載施設へ送るアンケート。回答 → スプレッドシート → `data/import_template.csv` の形に整えて Supabase へインポートし、`facilities` の属性を埋める。

> これは**施設からの情報**を集めるフォーム（自由記述あり）。受診者の口コミ（選択式・承認制・自由記述なし）はアプリ内の別機能なので混同しない。

## 設計方針

- boolean 項目はすべて **「対応している／対応していない／未定・無回答」** の3択。
  - 「対応している」→ `TRUE`、「対応していない」→ `FALSE`、未定・無回答 → **空欄（null）**。
- 推測で埋めない。分からない項目は空欄のまま。
- フォーム冒頭に用途と掲載趣旨、免責（私的な市民活動である旨）を明記。

## 質問項目（→ `facilities` カラム対応）

| # | 質問文（フォーム表示） | 形式 | カラム |
|---|---|---|---|
| 1 | 医療機関名 | 記述（必須・識別用） | `name`（照合キー） |
| 2 | 女性医師による大腸内視鏡検査は可能ですか | 3択 | `has_female_doctor` |
| 3 | 鎮静（静脈麻酔等）に対応していますか | 3択 | `has_sedation` |
| 4 | 土日の内視鏡検査に対応していますか | 3択 | `weekend` |
| 5 | 当日・翌日の予約は可能ですか | 3択 | `quick_reservation` |
| 6 | 駐車場はありますか | 3択 | `parking` |
| 7 | ネット予約は可能ですか | 3択 | `online_reservation` |
| 8 | 下剤（前処置）を院内で服用できますか | 3択 | `in_clinic_prep` |
| 9 | 車椅子・バリアフリーに対応していますか | 3択 | `barrier_free` |
| 10 | クレジットカードは使えますか | 3択 | `credit_card` |
| 11 | 大腸CT（CTコロノグラフィ）に対応していますか | 3択 | `ct_colonography` |
| 12 | 最寄り駅 | 記述（任意） | `nearest_station` |
| 13 | 最寄り駅からの徒歩分数 | 数値（任意） | `walk_minutes` |
| 14 | 公式サイトURL | 記述（任意） | `website` |
| 15 | 受診を検討している方へのひとこと（前処置の説明、注意点など） | 段落（任意・**自由記述可**） | `form_note` |

3択の選択肢ラベル（共通）：

```
・対応している
・対応していない
・未定 / わからない
```

## 回答 → CSV 変換メモ

- スプレッドシートの各列を `import_template.csv` のヘッダ名に対応させる。
- 3択を `TRUE` / `FALSE` / 空欄 に置換（例：スプレッドシート関数や一括置換）。
- `exam_types` はフォームでは聞かない（名簿時点で `{大腸内視鏡}`）。CTコロノ対応なら別途 `{大腸内視鏡,大腸CT検査}` に手修正。
- `municipality` / `address` / `phone` / `source_url` は登録名簿の値を維持（フォームでは上書きしない）。
- 人間が最終チェックして `verified=TRUE` に更新。
